# Amendment v1.2 — UI stack

Supersedes the A7 dependency list in v1.1 where in conflict.

## Decision

shadcn/ui is generated by `npx shadcn@latest init`, which produced a base-ui stack, not Radix. We keep it.

## Stack as built

- UI primitives: `@base-ui/react` (Tooltip, Button). Tooltip is required by the flag-label rules.
- Class helper: `cn` npm package, imported by generated `lib/utils.ts` and `components/ui/button.tsx`.
- Styling: Tailwind CSS 4.1.11 with `@tailwindcss/postcss` 4.1.11, `tw-animate-css`, `class-variance-authority`, `lucide-react`.

## Not used

`clsx`, `tailwind-merge`, `tailwindcss-animate`, `@radix-ui/react-*`. Do not add them.

## Notes

- Tailwind 3.4 pin from the original spec is superseded by Tailwind 4.1.11.
- Do not hand-roll `cn()` or remove the Tooltip primitive.
